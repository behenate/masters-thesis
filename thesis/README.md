# Thesis
This directory contains the LaTeX project used to generate the final thesis `.pdf` file

## Setup
It is recommended to develop this using Tex Live and the LaTeX workshop VSCode extension.

In order to setup the environment, before the first build, run `setup.sh` to create directory structure required by the `LaTeX` compiler.
Also make sure to add the contents of  `vscode.settings.template` into your vscode settings (`.vscode/settings.json`)
